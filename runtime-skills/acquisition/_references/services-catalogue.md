# FUTUREUNI services catalogue

FUTUREUNI ships four services. Package names in this file match the `PricingPackage.name`
strings on each service-line profile. **Prices live on the profile**, not here — they can
drift, so the model reads them from the profile at call time. Never quote a number that
isn't in the supplied input.

## 1. Web Development

Websites, storefronts and web apps built to be fast on Nigerian mobile data and
accessible on any device.

- **Starter site** — up to 5 pages, mobile-first, contact form, basic SEO. Timeline 3–5 weeks.
- **Growth site** — up to 10 pages, custom design system, blog/content sections, SEO + analytics setup. Timeline 5–8 weeks.
- **Ecommerce starter** — product catalogue, cart + checkout, payment integration, order-management basics. Timeline 6–10 weeks.

FUTUREUNI does **not** build: bespoke enterprise ERPs, banking-grade compliance
integrations, or mobile-only native apps.

## 2. UI/UX Design

Product research, flows, design systems and prototypes for teams shipping web or mobile
products.

- **UX audit** — heuristic review, 3 flow captures, priority issue list, 1-page report. Timeline 2–3 weeks.
- **Flow redesign** — research, IA + wireframes, hi-fi mockups, prototype. Timeline 4–8 weeks.

FUTUREUNI does **not** ship: front-end code from the UX package (that's Web Development),
or standalone illustration work (that's Graphic Design).

## 3. Graphic Design

Visual identity, brand systems and print/digital design.

- **Logo and basics** — logo, colour palette, type pairing, 1-page style guide. Timeline 2–3 weeks.
- **Brand system** — logo suite, full palette + type scale, social templates, guide. Timeline 4–6 weeks.

FUTUREUNI does **not** ship: video production (that's Video Editing), or product UI
mockups (that's UI/UX).

## 4. Video Editing

Editing, captions and thumbnails for creators, coaches and brands who post video.

- **Single edited video** — trim + colour, captions, thumbnail. Timeline 1–2 weeks.
- **Creator retainer (4 videos a month)** — editing, captions, thumbnails, publish support. Monthly retainer.

FUTUREUNI does **not** ship: original filming/production, or scripted screenplay writing.

## Cross-cutting rules

- **No client names or portfolio items unless supplied in the input.** If a portfolio
  proof isn't in the input, don't invent one.
- **Timelines are the profile's, not yours to change.** If the input doesn't include a
  timeline, don't invent a date.
- **Every package here matches a `PricingPackage.id` on the profile.** Use the profile's
  package `id`s when referencing packages in structured output.
