# src/styles/

**Owner: Phase 04 (Design system and shell).** Design tokens and global styles. Phase 1 seeded `tokens.css` (the only file with raw colour values, light on `:root` and dark on `[data-theme="dark"]`), `globals.css` (Tailwind CSS 4 and the `@theme inline` mapping) and `fonts.ts` (the ADR-014 faces through `next/font`); Phase 4 owns and refines them. Values come from `.claude/project-rules.md` §"Brand and UI", and changing a listed value needs a new contrast check.
